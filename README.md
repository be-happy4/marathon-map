# 我的省会马拉松足迹地图

网站有两个页面，共用同一份数据：

- **地图页**（`index.html`）：把「已完赛的省会马拉松」按省份画成中国地图，省份颜色越深 = 完赛场次越多，省份上标注该省最快官方净成绩（紧凑写法，249 = 2:49）
- **明细页**（`detail.html`）：把**全部**完赛场次列成表格，可按组别 / 标签 / 年份筛选、按关键字搜索、点列头排序

纯静态网页，双击打开即可，无服务器、无外网依赖（除了拉 Notion 数据那次）。

数据文件里存的是**全部**完赛场次（含半马、越野、十公里、非省会城市），地图只画其中标签含「省会」的那些——两个页面读的是同一份数据。

## 怎么打开

**线上（随时可看，手机也行）**

- 地图页：https://be-happy4.github.io/marathon-map/
- 明细页：https://be-happy4.github.io/marathon-map/detail.html

本地：双击项目目录下的 `index.html` 即可打开（纯静态页面），从表格下方的入口进明细页，或直接双击 `detail.html`。同步完数据后刷新即可。

线上是 GitHub Pages，push 后最多 10 分钟生效（缓存 `max-age=600`），急看看不到就强制刷新。

## 维护：数据更新（推荐：只改 Notion，一条命令出图）

维护方式只写在本文档，两个网页上都不放。

**唯一真源是 Notion「Games」库**，`data/races.js` 由脚本自动生成，不要手工改它。

1. 在 Notion 里把一场比赛标成 `Status = Completed`（完赛）——**所有**完赛场次都会进数据文件；想让某场出现在地图上，再给它勾上 `Extra Tag` 里的「省会」
2. 在 `marathon-map/` 目录运行：

   ```bash
   python3 sync.py
   ```

3. 刷新页面 → 地图的颜色、最快用时、统计表，以及明细页的表格，都自动更新

脚本会读取同目录 `.env` 里的 `NOTION_TOKEN`（integration token），把全库 `Status = Completed` 的场次（全马 / 半马 / 十公里 / 越野、是不是省会在内）连同等级、配速、标签、视频链接一起写进 `data/races.js`。城市是从赛事名里认出来的，认不出就留空——**不影响地图，地图只认标签**。标签只留「省会」「CMM」「WMM」三个，其余的在同步时就被丢掉（见下文「标签只留三个」）。

没有网络 / 没配 token 时想临时手动改：直接编辑 `data/races.js` 里的 `window.RACES`，照现有行的样子加一条：

```js
{ city: '南京', capital: '南京', date: '2026-03-15', year: 2026, name: '2026南京马拉松', group: 'Full Marathon', netSec: 10159, paceSec: 238, cnLevel: 'A', tags: ['省会'] },
```

**上地图要同时满足两条**：`tags` 里有一项独立等于 `'省会'`（多标签不影响，`['省会','CMM']` 算），**且**赛事名里出现了省会城市名（`capital`）。`city` / `capital` 认不出可以留空，`date` / `paceSec` / 等级 / 链接都可省略。下次跑 `sync.py` 这些手改会被覆盖。

数据源只有 `data/races.js` 这一处，不要直接改 `app.js` 里的数字——颜色深浅、最快用时、省份统计和明细表都由它自动算出。

## 地图收录口径

筛选只做一件事：**`Status = Completed` 且 `Extra Tag` 里有一项精确等于「省会」**。这条同时是代码里唯一的开关——改标签就改地图。

- 多标签算（`['省会','CMM']` 计入），相近标签不算——「省会半马」不是「省会」，而且它根本没进数据文件，见下文
- **不看组别**：全马 / 半马 / 十公里 / 越野，只要打了「省会」标签就收录。旧版「半马只计拉萨、西宁」那条代码规则已取消，改成由 Notion 标签把关
- 直辖市（北京/上海/天津/重庆）的马拉松计入对应省市
- 打标签**还不够**：赛事名里还得出现省会城市名（数据文件里的 `capital` 字段）。只打了标签、名字里没有省会的（比如给「2025西湖半程马拉松」打上「省会」），不会画进图里，页面下方会单独列出来提示
- 字段依赖：赛事名里出现的省会城市（`capital`）、比赛日期、年份、赛事名、组别、净成绩（`netSec` ← `Net Time(Seconds)` 公式，缺失时解析 `Net Time` 文本）、配速（`paceSec` ← `Seconds/km` 公式）、中国田协等级（`cnLevel`）、世界田联等级（`waLevel`）、标签（`tags`，只含省会 / CMM / WMM）、视频链接与状态（`videoUrl` / `videoStatus`）、赛事链接（`url`）
- 本页是**足迹记录**，与 `CHALLENGE.md` 的「省会破三」达标口径是两件事：挑战规则管的是成绩达标，这里管的是把跑过的省会画上去

**明细页不受上面这条约束**：它展示 `data/races.js` 里的全部完赛场次，不需要任何标签。

### 标签只留三个

`sync.py` 顶部有一张白名单 `KEEP_TAGS`：**只有「省会」「CMM」「WMM」会写进数据文件**。Notion 的 `Extra Tag` 里其它的标签（直通、江苏、浙江、省会半马……）想打就打，同步时一律丢掉，不进页面。

- 「省会」是地图开关，「CMM」（中国大满贯）「WMM」（世界大满贯）是荣誉标记
- 因此明细页的标签列与标签筛选项只会出现这三个；标签一多筛选栏就没法用了，所以宁可白名单窄一点
- **以后想按新标签筛选，得先把名字加进 `sync.py` 的 `KEEP_TAGS`**，光在 Notion 里打标签不会出现在页面上

### 两个「城市」字段别搞混

`sync.py` 会解析出两个不同的东西，分别给两个页面用：

| 字段 | 含义 | 谁在用 |
|---|---|---|
| `city` | **举办地级市**，从赛事名里的地名推（诸暨→绍兴、奉化→宁波、太仓→苏州、西湖→杭州） | 明细页的「城市」列 |
| `capital` | **赛事名里出现的省会城市**，没有就不写这个字段 | 地图页认省份 |

分开是因为口径不同：`2025西湖半程马拉松` 的举办地是杭州，但按 `CHALLENGE.md` 的命名口径它不以省会命名，不该算作杭州。两条判断各问各的问题。**目前 29 场里 9 场有 `capital`**，地图上的 6 场是这 9 场里又打了「省会」标签的。

地名表在 `sync.py` 的 `PLACE_TO_CITY`（含区县 / 县级市 / 地标）。以后跑了新城市而页面显示「—」，就是那张表里没有——把地名加进去即可；表里已有的会一直生效。

## 文件结构

```
marathon-map/
├── index.html            # 地图页入口（双击打开）
├── detail.html           # 明细页：全部完赛场次，可筛选 / 搜索 / 排序
├── README.md             # 本说明
├── CHALLENGE.md          # 「省会破三」挑战规则
├── sync.py               # ★ 自动同步脚本：Notion API → 生成数据文件
├── .env                  # Notion token（含密钥，勿提交/外传；可随时在 Notion 里撤销重建）
├── .gitignore            # 忽略 .env
├── style.css             # 两页共用：CSS 变量、浅深主题、页面骨架、表格
├── format.js             # 两页共用：成绩 / 配速 / 等级 / 组别的格式化与中文字典、转义、主题偏好
├── app.js                # 地图页逻辑（按标签筛选、省份归并、聚合、地图与汇总表）——不用改
├── detail.js             # 明细页逻辑（筛选、排序、表格渲染）
├── data/
│   └── races.js          # 全部完赛场次（sync.py 生成；两个页面都读它）
└── lib/
    ├── china.js          # 中国省份底图（离线）
    └── echarts.min.js    # 图表库（离线，只有地图页需要）
```

两个页面都用普通 `<script>` 引 `format.js`（不是 ES module）——`file://` 下用 `import` 会被 CORS 拦掉，双击就打不开了。想加第三个视图，照 `detail.html` 的样子新建一个页面、共用 `style.css` + `format.js` 即可。

## 主题与交互

两页共用一个主题偏好（`localStorage` 的 `mmap-theme`）：在任一页切换，另一页也跟着变；没有手动切过就跟随系统。

**地图页**

- 右上角「导出图片」按钮：把当前主题下的地图存为 PNG（2× 清晰度），文件名带当天日期
- 地图可拖拽、滚轮缩放（看北京、上海等小省份）
- 悬浮省份显示场次与最快净成绩
- 下方明细表逐场列出日期、赛事全称、净成绩、等级、配速、视频（可点，新窗口打开），按日期倒序（最新在最上）；表格下方有进入明细页的入口
- 「等级」列**只显示世界田联标牌等级**（白金标 / 金标 / 精英标 / 标牌），没打标的显示「—」，不退回中国田协等级

**明细页**

- 筛选：关键字搜索（赛事名 / 城市 / 日期 / 中文组别 / 标签）+ 组别、标签、年份三行标签按钮；同一行内多选是「或」，跨行是「且」，可叠加
- 排序：点列头切换升 / 降序，箭头标在当前排序列上；**缺失值不分升降序一律排在最后**
- 全字段：日期 / 赛事名 / 城市 / 组别 / 净成绩 / 配速 / 世界田联等级 / 中国田协等级 / 标签 / 视频 / 成绩页
- 「城市」是**举办地级市**（和地图页的 `capital` 不是一回事，见上文），目前 29 场都能解析出来
- 组别与世田联等级显示中文，中田协等级沿用原始的 A / A1 / A2 / B / C
- 选项和场次数都从数据里现算：Notion 里新加**组别**，页面自动出现新选项；新加**标签**则要先把名字加进 `sync.py` 的 `KEEP_TAGS`（见上文「标签只留三个」），否则连数据文件都进不去

两页在窄屏下表格都是**容器内横向滚动**，页面本身不会被撑宽。
